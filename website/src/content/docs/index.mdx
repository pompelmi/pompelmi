# Pompelmi

Your file upload endpoint is part of your attack surface.

Pompelmi is the open-source, in-process upload security layer for Node.js. It scans and blocks risky uploads before storage or downstream processing, with no cloud API and no daemon.

Works with Express, Next.js, NestJS, Fastify, and Koa. The MIT-licensed core is the primary path.

## Why this matters

Most upload handlers stop at extension checks or client-provided MIME types. Pompelmi adds a layered upload gate before files hit storage or downstream processing.

Without Pompelmi:

`upload -> trust filename/MIME -> store -> parse or serve later`

With Pompelmi:

`upload -> inspect bytes + structure -> allow | quarantine | reject -> store/process`

## Quick start

```bash
npm install pompelmi
```

```ts
import { scanBytes, STRICT_PUBLIC_UPLOAD } from 'pompelmi';

const report = await scanBytes(fileBytes, {
  policy: STRICT_PUBLIC_UPLOAD,
  filename: 'upload.pdf',
  mimeType: 'application/pdf',
  failClosed: true,
});

if (report.verdict !== 'clean') {
  // block, quarantine, or escalate based on your policy
}
```

## What it helps block

| Risk | What Pompelmi checks |
| --- | --- |
| Spoofed or renamed files | Extension policy, declared MIME checks, and magic-byte validation |
| Archive bombs and traversal | Entry count, total extracted size, nesting depth, and archive path guards |
| Risky document structures | Heuristics for polyglots, executable signatures, and script-bearing documents |
| Environment-specific threats | Optional YARA rules in a composed scanner pipeline |
