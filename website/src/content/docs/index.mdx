# Pompelmi

Pompelmi is an open-source upload gate for Node.js. It inspects untrusted files before storage or downstream processing with in-process, local-first checks for spoofed types, archive abuse, and risky document structures.

It is designed for the point where your application decides whether an upload is safe enough to keep, quarantine, or reject.

## Start here

```bash
npm install pompelmi
```

## What Pompelmi helps with

- File-type spoofing where the extension and declared MIME are not trustworthy.
- ZIP archives that can hide traversal, deep nesting, or decompression abuse.
- Risky PDF, SVG, Office, and polyglot structures that are not visible from metadata alone.
- Optional YARA matching when the built-in heuristics are not specific enough for your environment.

## What it does not claim to be

- Not a full endpoint protection platform.
- Not a replacement for storage isolation, auth, logging, or incident response.
- Not a compliance certification.

Use it as an application-layer control at the upload boundary.

## Minimal core example

```ts
import { scanBytes, STRICT_PUBLIC_UPLOAD } from 'pompelmi';

const report = await scanBytes(fileBytes, {
  filename: 'upload.pdf',
  mimeType: 'application/pdf',
  policy: STRICT_PUBLIC_UPLOAD,
  failClosed: true,
});

if (report.verdict !== 'clean') {
  // reject or quarantine based on your policy
}
```
