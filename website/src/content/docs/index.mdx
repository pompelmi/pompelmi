# Pompelmi

Secure file uploads for Node.js.

Pompelmi is the open-source upload gate for Node.js. It inspects untrusted files before storage or downstream processing with in-process, local-first checks. Start here if filenames, extensions, or client-provided MIME types are not enough for your upload flow.

## Why teams use it

Most upload handlers still do some version of:

`upload -> trust filename/MIME -> store -> parse or serve later`

Pompelmi changes that to:

`upload -> inspect bytes + structure -> allow | quarantine | reject -> store/process`

## Quick start

```bash
npm install pompelmi
```

```ts
import { scanBytes, STRICT_PUBLIC_UPLOAD } from 'pompelmi';

const report = await scanBytes(fileBytes, {
  policy: STRICT_PUBLIC_UPLOAD,
  filename: 'upload.pdf',
  mimeType: 'application/pdf',
  failClosed: true,
});

if (report.verdict !== 'clean') {
  // reject, quarantine, or escalate based on your policy
}
```

## What it checks

| Risk | What Pompelmi checks |
| --- | --- |
| Spoofed or renamed files | Extension policy, declared MIME checks, and magic-byte validation |
| Archive bombs and traversal | Entry count, total extracted size, nesting depth, and archive path guards |
| Risky document structures | Heuristics for polyglots, executable signatures, and script-bearing documents |
| Environment-specific threats | Optional YARA rules in a composed scanner pipeline |

## Who it is for

- Public or semi-trusted upload endpoints.
- Privacy-sensitive or self-hosted environments.
- Teams that want a typed upload-security layer rather than a chain of ad hoc checks.

## Why not just MIME checks or a daemon-based scanner?

| Approach | Useful for | Gap |
| --- | --- | --- |
| MIME or extension checks only | Basic allowlists and cheap filtering | They still rely on metadata or filenames the client controls. |
| DIY validation | Full control over your own rules | Archive handling, structured verdicts, and fail-closed behavior are easy to underbuild. |
| Cloud scanning APIs | Managed detection | Adds data egress, network latency, and a hard external dependency. |
| Daemon-based AV | Signature scanning and existing security tooling | Solves a different layer from the application-level upload gate before storage. |

Pompelmi focuses on the upload gate itself. It can complement YARA or daemon-based scanners. It is not presented as a full antivirus replacement.
