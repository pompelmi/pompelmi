# Pompelmi

Pompelmi is a TypeScript-first upload security layer for Node.js applications.

It helps teams block risky uploads before they hit durable storage, with controls that are straightforward to test, observe, and tune.

## Why teams evaluate it

- In-process scan path with no required cloud dependency.
- Layered checks for common upload attack patterns.
- Framework adapters for common Node.js stacks.
- Structured scan outcomes that fit operational workflows.

## Quick start

```bash
npm install pompelmi
```

```ts
import { scanBytes, STRICT_PUBLIC_UPLOAD } from 'pompelmi';

const report = await scanBytes(fileBytes, {
  policy: STRICT_PUBLIC_UPLOAD,
  filename: 'upload.pdf',
  mimeType: 'application/pdf',
  failClosed: true,
});

if (report.verdict !== 'clean') {
  // block, quarantine, or escalate based on your policy
}
```

## Core capabilities

- Size limits and extension policy checks.
- Magic-byte validation to detect disguised files.
- Structural heuristics for high-risk payload patterns.
- Archive risk controls for ZIP-heavy attack classes.
- Optional YARA integration.
- Composable scanner orchestration.
