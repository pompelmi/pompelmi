# Commercial engagements

Pompelmi is MIT-licensed open source.

For teams that need help in production, commercial engagements are available for:

- architecture and threat-model reviews
- integration support for your framework and deployment model
- scanner and policy tuning for your risk profile
- rollout and incident-response planning

## What is included in the open-source core

- file scanning and policy evaluation
- framework adapters and examples
- local-first processing in your own runtime

## What is not implied

- no proprietary enterprise package in this repository
- no fixed-price plan published in this document
- no guaranteed SLA unless explicitly contracted

## Contact

If you want a scoped support plan, open a discussion in the repository and include your requirements:

- expected traffic and file sizes
- required response windows
- regulatory or audit constraints
- target timeline
