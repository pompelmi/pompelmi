# S3 Integration

pompelmi can scan S3 objects directly without downloading them to disk first.
The object body is streamed to clamd via the INSTREAM protocol — no temporary files, no extra memory buffering.

## Requirements

Install the AWS SDK in your project:

```bash
npm install @aws-sdk/client-s3
```

pompelmi does not bundle the AWS SDK. It is an optional peer dependency — install it only when you need S3 scanning.

---

## Basic usage

```js
const { scanS3, Verdict } = require('pompelmi');

const result = await scanS3(
  { bucket: 'my-uploads', key: 'incoming/document.pdf', region: 'us-east-1' },
  { host: '127.0.0.1', port: 3310 }
);

if (result === Verdict.Clean)     console.log('Safe.');
if (result === Verdict.Malicious) throw new Error('Malware detected — delete the object.');
if (result === Verdict.ScanError) console.warn('Scan incomplete — treat as untrusted.');
```

`scanS3` passes all standard scan options through to `scanStream`, so you can use `socket`, `host`, `port`, `timeout`, `retries`, and `retryDelay`.

---

## IAM permissions

Your execution role needs `s3:GetObject` on the target bucket:

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::my-uploads/*"
    }
  ]
}
```

## Passing credentials explicitly

If your environment does not have ambient AWS credentials (e.g. when running locally without an IAM role), pass them directly:

```js
const result = await scanS3(
  {
    bucket: 'my-uploads',
    key:    'file.zip',
    region: 'eu-west-1',
    credentials: {
      accessKeyId:     process.env.AWS_ACCESS_KEY_ID,
      secretAccessKey: process.env.AWS_SECRET_ACCESS_KEY,
    },
  },
  { host: '127.0.0.1', port: 3310 }
);
```

When `credentials` is omitted, the SDK's default credential chain is used (environment variables, `~/.aws/credentials`, EC2/Lambda instance metadata, etc.).

## Lambda example — scan on S3 put

This Lambda function is triggered by an S3 `ObjectCreated` event. It scans the new object and deletes it if infected.

```js
const { S3Client, DeleteObjectCommand } = require('@aws-sdk/client-s3');
const { scanS3, Verdict } = require('pompelmi');

const s3 = new S3Client({});

exports.handler = async (event) => {
  for (const record of event.Records) {
    const bucket = record.s3.bucket.name;
    const key    = decodeURIComponent(record.s3.object.key.replace(/\+/g, ' '));

    console.log(`Scanning s3://${bucket}/${key}`);

    const result = await scanS3(
      { bucket, key, region: process.env.AWS_REGION },
      { host: process.env.CLAMD_HOST || '127.0.0.1', port: 3310, retries: 2 }
    );

    if (result === Verdict.Malicious) {
      console.warn(`INFECTED: s3://${bucket}/${key} — deleting.`);
      await s3.send(new DeleteObjectCommand({ Bucket: bucket, Key: key }));
    } else if (result === Verdict.Clean) {
      console.log(`Clean: s3://${bucket}/${key}`);
    } else {
      console.error(`ScanError: s3://${bucket}/${key} — leaving in place, manual review needed.`);
    }
  }
};
```

**Architecture:** run clamd as a sidecar container or ECS service on the same VPC as the Lambda. Point `CLAMD_HOST` at its private IP or service discovery DNS name.

## Scan before upload (pre-upload pattern)

Scan a local file before uploading to S3 so infected files never reach the bucket:

```js
const { PutObjectCommand, S3Client } = require('@aws-sdk/client-s3');
const { scan, Verdict } = require('pompelmi');
const fs = require('fs');

const s3 = new S3Client({ region: 'us-east-1' });

async function safeUpload(filePath, bucket, key) {
  const verdict = await scan(filePath, { host: '127.0.0.1', port: 3310 });

  if (verdict !== Verdict.Clean) {
    throw new Error(`Upload rejected: ${verdict.description}`);
  }

  await s3.send(new PutObjectCommand({
    Bucket: bucket,
    Key:    key,
    Body:   fs.createReadStream(filePath),
  }));

  console.log(`Uploaded clean file to s3://${bucket}/${key}`);
}
```

## Retry on transient errors

S3 downloads or clamd connections can occasionally fail. Use `retries` to recover automatically:

```js
const result = await scanS3(
  { bucket: 'my-uploads', key: 'large-archive.zip', region: 'us-east-1' },
  { host: '127.0.0.1', port: 3310, retries: 3, retryDelay: 500 }
);
```
